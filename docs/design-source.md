# Visual Design Source

## Direction
Professional interview operations workspace. The visual language uses an editorial light interface, dense panels, visible state, fine borders, and product-like preview blocks inspired by modern design-system galleries.

## Style Rationale
- Direction A: bright SaaS landing page. Rejected because it makes the tool feel generic and soft.
- Direction B: editorial career site. Rejected because the user asked for a professional tool station, not a content blog.
- Direction C: editorial practice workbench. Selected because interview prep benefits from focus, clear state, timer prominence, and structured feedback without relying on glossy automation cues.

## Design Tokens

- Secondary background: #e8ece8

- Strong panel: #ffffff
- Text: #171717
- Muted text: #626660
- Accent cobalt: #1d5f8f
- Accent brick: #a74635
- Accent olive: #617148
- Accent amber: #b98522
- Radius: 8px

## Key States
- Role selected / unselected.
- Timer running / paused / reset.
- Question selected.
- Rubric score changed.
- Report export.
- Mobile stacked layout.

## Handoff Notes
- Keep the tool visible above the fold on desktop after the hero.
- Do not replace the practice panel with a marketing card.
- Do not add vague automation claims unless a real backend is connected and reviewed.
