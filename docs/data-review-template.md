# Data Review Template

## Status Buckets
- verified
- partial
- missing
- waiting_platform_refresh

## Daily Review
- Sessions started.
- Sessions completed.
- Report exports.
- Timer starts.
- Role selections.
- Errors or broken links.
- User feedback.

## Weekly Review
- Traffic sources.
- Query impressions and clicks.
- First-session completion rate.
- Export rate.
- Most selected role and format.
- Top abandonment point.

## Decision
- Kill: no engagement and no clear fix.
- Iterate: one to three high-ROI changes are visible.
- Scale: acquisition and product activation both show signal.
